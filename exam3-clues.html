How to use this activity

This is the crossword in list form: each clue has its own answer box. Type an answer, then press Enter or move to the next box to save it.

The squares under each clue show letters you have already filled in from crossing answers, just like in a crossword grid. Screen readers read these letters as part of each answer box's description.

Check tells you whether an answer is right and marks wrong letters with a slash. Reveal fills in the answer for you. Your answers are shared with the Crossword and saved in this browser when possible.
